# 🚀 ESP32 + EC200U-CN Cellular IoT Projects

A hands-on Embedded Systems and Cellular IoT learning journey using an
ESP32-WROOM-32E and Quectel EC200U-CN LTE modem.

This repository documents a progressive series of practical projects
designed to build real-world skills in:

- Embedded Systems
- MicroPython
- UART communication
- AT command interfaces
- Cellular modem integration
- SIM management
- LTE network registration
- IoT communication
- Cloud connectivity
- Industrial IoT

The projects are developed incrementally, with an emphasis on understanding
the hardware, communication protocols, firmware architecture, debugging
techniques, and engineering practices behind each implementation.

---

## 🎯 Learning Objective

The goal of this project series is to progress from basic ESP32 hardware
diagnostics to complete cellular IoT applications.

cellular product:
